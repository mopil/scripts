# 거시경제 브리핑

오늘 거시경제 현황을 브리핑해줘.

---

## 분석 항목

1. **연준 금리/통화정책** - FOMC 결정, 금리 전망, 발언 요약
2. **GDP/인플레이션/실업률** - 미국 핵심 매크로 지표
3. **주요 지수** - S&P500, 나스닥, 다우 (전일 종가, 등락률)
4. **달러인덱스/10년물 금리** - DXY, US10Y
5. **금/유가** - Gold, WTI/Brent
6. **핵심 리스크** - 지정학, 관세, 정책 변수

---

## 실행 흐름

### 1. 데이터 수집
- **1차 소스**: `python scripts/macro/macro_screener.py` 실행하여 실시간 지표 데이터 수집
  - 15개 지표 (금리, 통화, 변동성, 주식, 원자재, 크립토)
  - 전일 등락, MA200 대비, 52주 고점 대비, 기간 변동률(1W/1M/3M)
  - Risk-On/Off 매크로 심리 판정
- **2차 소스**: WebSearch로 최신 거시경제 뉴스/정책 변화 병렬 검색
  - 스크리너에 없는 항목 보완 (연준 발언, GDP, CPI/PCE, 실업률 등)
- economist-analyst 스킬 프레임워크 활용하여 분석

### 2. 브리핑 작성
- 스크리너 실행 결과의 수치를 시장 동향 테이블에 직접 반영
- 테이블 형식 활용하여 간결하게 정리
- 환율 1450원 기준으로 원화 환산 병기
- 핵심 수치(가격, 변동률, 레벨) 반드시 포함
